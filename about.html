About Technical Windows

The person, the purpose, and why this channel exists.

Who's behind it

Technical Windows is created and run by Ganesh Ugale — a Computer Engineering graduate from Savitribai Phule Pune University (SPPU), Maharashtra, and currently a Software Engineer at Yardi Softwares India Pvt. Ltd.

The channel started as a way to help fellow SPPU students get through DS&BDA lab practicals without wasting hours hunting for working setup files — it's grown into a wider library of Hadoop, Python and Windows installation tutorials.

What we teach

  • Hadoop, MapReduce, Scala & Apache Spark for the SPPU DS&BDA lab
  • Python, Anaconda & Jupyter Notebook setup and basics
  • Windows software installation — Java, MySQL, VS Code and more
  • Practical coding setups for student projects

Our goal

Every SPPU student deserves clear, step-by-step guidance to finish their lab practicals and set up their environment without friction. All setup files, source code, and download links are provided directly on this website — so you never have to go searching in the comments section again.
